# toolshop-e2e

UI- и API-автотесты для [Toolshop](https://practicesoftwaretesting.com) на Playwright и TypeScript.

## Тесты запускаются только локально

Тесты идут на публичном демо-сайте, который защищён Cloudflare. С серверов GitHub Actions сайт показывает проверку «подтвердите, что вы человек», и тесты падают. Поэтому в CI проверяются только форматирование, линтер и типы, а сами тесты запускаются локально.
